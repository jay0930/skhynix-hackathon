# 사전 체험 점검

공개 키트에는 일반적인 점검 절차만 둡니다. 개인 접속 링크·신분 정보·PDF 원본과 상세 요약은 게시하지 않습니다. [confidence: high]

## 시작 전

- 본인의 공식 안내에서 시간·장비·촬영·신분증 가림 조건을 확인합니다.
- 실제 응시 장소에서 컴퓨터·휴대폰 전원과 네트워크를 준비합니다.
- 웹캠·Proctor·전체 화면 공유를 연결하고 촬영 구도를 확인합니다.
- 비허용 프로그램·알림·추가 모니터를 정리합니다.

## 15분 체험 권장 순서

시간 배분은 Wren의 제안이며 공식 배정 시간이 아닙니다. 감독 연결을 먼저 준비하고, 남은 시간에 맞춰 조정합니다. [confidence: medium]

| 체험 경과 | 확인할 내용 |
|---|---|
| 0~3분 | 감독 연결·README·터미널·파일 저장 |
| 3~6분 | README의 Clone 명령·출처 확인·Codex가 지침과 Skill을 직접 읽는지 |
| 6~10분 | 짧은 응답·런타임 버전·작은 터미널 테스트. 분담 지원은 가볍게 확인하고 미지원이면 단일 실행 |
| 10~12분 | 제공 예제로 서버·실제 포트·`0.0.0.0` 바인딩을 확인하고 플랫폼 Browser를 직접 조작 |
| 12~15분 | Cofa Helper 사용법·체험 종료·예시 후속 문항의 수동 진행 흐름 |

한 번뿐인 체험에서 전체 앱을 만들지 않습니다. 다운로드·설정이 차단되면 우회하지 않고 오류와 발생 시각을 기록해 신고합니다. [confidence: medium]

## 실제로 확인한 뒤 기록할 항목

| 항목 | 초기 상태 | 실제 결과 기록 |
|---|---|---|
| 공개 키트·자체 제작 공개 Skill 사용 가능 범위 | 미확인 | {{플랫폼 안내 또는 문의 결과}} |
| `/tmp` 다운로드·키트 읽기 | 미확인 | {{결과}} |
| Codex·허용 모델 | 미확인 | {{화면에서 확인한 모델}} |
| 다중 에이전트 지원 | 미확인 | {{지원 여부. 미지원이면 단일 실행}} |
| 테스트·서버·미리보기 | 미확인 | {{직접 확인 결과}} |
| 체험 파일이 본 과제에 유지되는지 | 미확인 | {{유지된다고 가정하지 않음}} |

시험 중에는 공개 키트를 가져오는 동작만 사용하고 결과를 Push하지 않습니다. 제출물 확정 후에는 수정할 수 없으므로 저장·필수 파일·검증 결과를 먼저 확인합니다. 후속 서술형부터는 AI 지원을 중단합니다. [confidence: high]
