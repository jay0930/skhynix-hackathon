## 대화 전환 검토

별도 읽기 전용 검토에서 초안 ‘인수인계 문서를 찾는 시간이 길어 검색 도우미를 만들고 싶다’를 사용해 Skill 지침이 요구하는 전환을 추적했습니다. [confidence: high]

| 입력 | 지침에 따른 동작 |
|---|---|
| 초안 제공 | 초안과 해석을 구분하고 중요한 질문 하나. 코드·문서 생성·자동 분담 없음 |
| 정리해줘 | 채팅 요약만 제공. 미정 정보는 미정으로 유지 |
| 이 방향으로 확정 | 확정된 범위만 과제 PRD에 기록. 미정 업무 조건을 추정해 채우지 않음 |
| 구현해줘 | 승인 반복 없이 환경·요구사항 확인 후 구현. 필수 입력·기대 결과·수용 기준이 없으면 해당 작업만 차단하고 질문 |
| 초안 없음 | 시작 아이디어를 요청. 대신 발명하지 않음 |
| 시험 중 외부 리뷰·Push | 수행하지 않고 허용된 내부 검토로 전환 |
| 후속 서술형 도움 | AI 지원 중단 |

검토 과정에서 준비 단계 게시와 시험 단계 Push 금지를 구분하고, 구현에 필수 업무 정보가 없을 때 질문·차단 기록을 남기도록 보완했습니다. 이는 지침을 읽어 추적한 검토이며 실제 모델이 모든 대화에서 같은 행동을 한다는 증명은 아닙니다. [confidence: high]
